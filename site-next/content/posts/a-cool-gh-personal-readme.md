# A Cool GitHub Personal README

Saved this as inspiration for building out my own GitHub profile README. A well-done profile page makes a solid first impression, especially for PM or tech roles.

## How to Set It Up

[Managing your profile README — GitHub Docs](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme)

The trick is creating a repo with the same name as your GitHub username — whatever you put in that repo's README.md shows up on your profile page.
