# Six Workplace Frameworks Worth Knowing

A checklist of classic workplace / management frameworks. Useful for structured thinking, project planning, and problem-solving.

## The Frameworks

- [ ] **PDCA循环** — Plan-Do-Check-Act: the classic continuous improvement loop
- [ ] **SWOT分析** — Strengths, Weaknesses, Opportunities, Threats analysis
- [ ] **SMART原则** — Goal-setting framework (Specific, Measurable, Attainable, Relevant, Time-bound)
- [ ] **6W2H法则** — Who, What, When, Where, Why, Which + How, How Much: a thorough questioning framework
- [ ] **重要&紧急象限** — The Eisenhower Matrix: prioritizing tasks by importance vs. urgency
- [ ] **WBS目标任务拆解法** — Work Breakdown Structure: decomposing big goals into manageable chunks

These are the kind of tools that sound basic until you actually start using them consistently. Then they become second nature.
